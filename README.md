# evatr-dotnet

Unofficial .NET client for the German BZSt eVatR API and the EU VIES API — NuGet package `Evatr.Net`.

> Not affiliated with the Bundeszentralamt für Steuern (BZSt) or the European Commission.

**Work in progress.** Package documentation: [src/Evatr.Net/README.md](src/Evatr.Net/README.md).

```sh
dotnet build
dotnet test --filter "Category!=Live"
```
